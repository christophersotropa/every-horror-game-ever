Our final project combines both horror game groups into one. It continues the "every horror game ever" idea and includes different levels/ scenes playing on typical horror game tropes. Levels like a puzzle level, an office level, a chase scene, etc will be present. Ideas for scenes/levels are being flushed out individually. The idea is to incorporate new elements such as NPCs, cutscenes, choices, subtitles, interactive objects. The main idea is to continue off the satirical element through elements listed.
